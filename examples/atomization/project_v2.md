# 근거 기반 AI 지식 검토 도우미

## 문서 수집
### 수신 정책
#### FE / BE
- 운영자가 승인한 경보만 수신한다.
- 승인되지 않은 문서는 검토 대기열에 보관한다.

## 지식 분석
### 모델 평가
#### ML / DL
- 문서 중복 후보의 고정 평가셋 정확도는 0.95 이상이어야 한다.
- 문서 도착 후 20초 이내에 검토 후보를 표시한다.

## 변경 검토
### 출처 추적
#### FE / BE / LLM
- 승인된 문서 변경만 적용하고 변경 결과를 기록한다.
- 외부 근거가 없으면 정책 충돌을 확정하지 않는다.

## 운영 복구
### 저장소
#### 인프라 / 데이터
- 장애 발생 후 2분 이내에 복구 절차를 시작한다.
- 원문과 관측값을 함께 백업한다.
