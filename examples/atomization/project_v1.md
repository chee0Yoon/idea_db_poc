# 근거 기반 AI 운영 도우미

## 사건 수집
### 수신
#### 중복 제어
##### 재시도
###### 승인 경계
###### FE / BE
- 운영자가 승인한 경보만 수신한다.
- 승인되지 않은 경보는 수신하지 않는다.
- 수신 결과를 변경 불가능한 감사 기록으로 보존한다.

## 사건 분석
### 모델 평가
#### ML / DL
- 경보 분류의 고정 평가셋 정확도는 0.90 이상이어야 한다.
- 로그 도착 후 30초 이내에 분류 결과를 표시한다.
- 입력 분포 변화가 0.30을 초과하면 모델 재검토를 요청한다.

## 대응 검토
### 근거와 실행
#### FE / BE / LLM
- 승인된 런북 단계만 실행하고 실행 결과를 기록한다.
- 외부 근거가 없으면 원인을 확정하지 않는다.
- 🔎 인용 문서의 해시를 화면에 표시한다.

## 운영 복구
### 저장소
#### 인프라 / 데이터
- 장애 발생 후 2분 이내에 복구 절차를 시작한다.
- 원문과 관측값을 함께 백업한다.
